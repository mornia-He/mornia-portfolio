PROJECT 01

数字体验设计

Digital Experience Design

探索数字媒介中的视觉体验， 通过交互装置、游戏视觉、 移动端界面以及Web体验设计, 建立人与视觉之间的连接。

设计方向

Interactive Design
UI Design
Digital Experience

设计工具

Illustrator
Photoshop
Figma
After Effects

项目内容

装置 / 游戏 / APP / Web

01

Interactive Installation

交互装置视觉设计， 通过视觉海报、制作过程以及现场展示， 呈现完整设计流程。

02

Game Visual Design

围绕游戏世界观， 完成AI角色生成、 线索卡、ICON以及游戏界面视觉设计。

03

Mobile APP UI

完成移动端产品界面设计， 包含首页、高保真界面以及引导页面。

04

Web UI Design

通过网页视觉系统， 构建Hero页面、长图展示以及视觉展板。

Design Approach

通过视觉语言、交互体验与数字媒介， 探索人与内容之间的连接方式。
